Make Defect Reporting a fast & convenient experience for citizens

Overview

Role UX UI Design
Employer make-better
Duration 3 weeks

Mein Duisburg is a mobile app made for citizens of Duisburg city in Germany. It's a "super" app that offers everything from what's happening in the city, run for the environment – Klimagold, checking out garbage collection schedule, finding charging stations to even report a defect to the city.

The objective of this feature was to help the residents report problems directly while on the go, without having to fill out complicated forms & the system automatically forwards reports to the responsible teams at the same time, Increase citizen participation by making the feature intuitive and trustworthy.

Discovery & research

User pain points

Before starting the design, I met with the Product Owner to understand existing user pain points:

  • No central place to report public defects but instead manual reports via email or phone
  • Reports were being made manually via email or phone, which felt slow and outdated
  • Lack of feedback loop after a report is submitted

Additional findings

  • Most of these problems are processed and resolved by the responsible authorities within two weeks.

Competitive Analysis Highlights

I researched similar civic platforms across Germany to identify best practices and opportunities:

  • Speed is critical: The flow should allow users to submit a report in under 2 minutes — AI can help accelerate this.
  • Location accuracy: Automatically detect the user's position with an option to adjust manually.
  • Progress visibility: Users expect status updates — e.g. "Defect received" or "Issue resolved" — via push or email notifications.
  • Friendly & accessible design: All citizens, regardless of tech-savviness, should feel comfortable using the feature.

These findings guided us in designing a reporting flow that's not only efficient and clear but also builds user trust.

Define

Information Architecture

Based on the research findings, I mapped out the core user flows — from entry point in the app to submission confirmation. The report flow was structured into four focused steps to reduce cognitive load and keep each screen to a single decision.

User flow

The primary user flow covers the main reporting path: taking or uploading a photo → confirming AI-generated details → verifying location → reviewing and submitting. An optional path was added to allow reports without photos.

Key design decisions

  • Citizens should not need to know which department handles which defect type — routing is automatic
  • GPS location defaults to current position with a manual override option
  • AI-generated fields are clearly labelled and always editable before submission
  • A unique report ID and next-step explanation is shown immediately after submission

Design

Wireframing

Low-fidelity wireframes were used to validate the four-step flow with the product team before committing to visual direction. A quick usability session with five citizens surfaced three key friction points before high-fidelity work began.

Usability testing insights

  • Users wanted to skip photos for defects that are hard to photograph — we added an optional path
  • The AI-generated description confused two participants — we added a clearer "AI-assisted, you can edit" label
  • The step indicator was not visible enough on the photo screen — contrast and step labels were improved

Final screens

The final UI follows a clean four-step flow that stays true to the Mein Duisburg design system. Key components include the photo upload guide, AI content disclosure card, GPS map confirmation, and submission summary screen.

Progressive disclosure AI-assisted form fill GPS location input Step indicator Feedback loop Accessibility

Outcome

The redesigned defect report feature shipped as part of the Mein Duisburg app update in 2023. The step-by-step flow with AI assistance significantly reduced submission time and lowered the barrier for first-time users.

<60s Avg. submission time in testing
~80% AI category pre-fill accuracy
2 wks City resolution time

The design pattern was later reused as a template for additional reporting flows in the app. The project reinforced the value of progressive disclosure and transparent AI interactions — two principles I now apply as defaults in any form-heavy flow.
